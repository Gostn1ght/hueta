# Повтор бартера и пассажирской посадки

Повтор владельца: клики и перетаскивание не предлагают вещи, нет явных границ между предложением и инвентарём, деньги ведут себя неверно, экипировку приходится предварительно снимать. Пассажиры скручены, смотрят вбок и проваливаются в сиденья на разных моделях. ИГРА-02 переоткрыта; повторы добавлены в АВТО-07/08.

Найдена конкретная причина ввода: UIBarter не вызывал UICellContainer:OnKeyboard. В базовом utils_ui контейнеры получают мышь только через владельца окна; прежняя проверка вызывала On_CC_Mouse1 напрямую и не покрывала этот путь. Добавлена передача событий и отдельная регрессия с настоящими методами базового контейнера (SHA исходника сохранён в fixture). При отпускании перетаскивания получает событие только исходный контейнер, без случайного клика по предмету назначения.

Предлагать теперь можно экипированные и поясные вещи; предметы остаются у владельца до подтверждения, сервер повторно проверяет владельца/квестовый запрет. Экипировка обновляется из подтверждённого состояния. Деньги и готовность отправляются одной командой ready/version/amount: изменение суммы сбрасывает старое согласие партнёра, устаревшая версия не проходит. Набираемая сумма сохраняется при обновлении предложения партнёра. Состояние персонажа разделено на три надписи вместо необрабатываемых переносов строк. Области предметов получают отдельные рамки; нарисованные пустые слоты убраны из фоновой панели.

Локальные проверки Lua 5.1 клиента и сервера успешны, включая настоящий путь мыши, перетаскивание, экипировку/пояс, сумму и гонку готовности. Проверка внутри игры и выпуск не выполнены; задача остаётся открытой. Качественные пассажирские движения и контакт с конкретными сиденьями продолжают проверяться отдельно.
