# Сохранение оригинальной палочки после броска

13 ноября 2026. Не выпущено; АНИМ-09 остаётся открытым.

## Конфликт двух реализаций

Нативное UpdateWorldGlow из cf4442f59 освещает тот же сетевой inventory object без нового ALife-объекта. Но исходный GAMMA zz_glowstick_mcm.actor_on_item_drop ставит таймер spawn_glowstick, который на сервере с ALife создаёт lights_glowstick и удаляет оригинал через alife_release_id. actor_on_item_drop разрешён серверным слоем совместимости. Это конфликтует с сохранением uid/владения и нативным светом; на чистом клиенте первоначальная функция просто прекращалась из-за отсутствия alife_object.

В серверный on_game_start добавлена идемпотентная обёртка spawn_glowstick. Для предметов с явным флагом netcoop_world_glow она подтверждает таймер без создания лампы/удаления оригинала. Старый actor_on_item_drop обращается к функции через окружение скрипта, поэтому зарегистрированный callback сохраняется, а поставленный им таймер получает обёртку. Остальные предметы/неизвестные ID передаются прежней функции с теми же аргументами. Клиентский скрипт и HUD-анимации не менялись.

Исполняемая проверка check-netcoop-world-glow-compat.py извлекает настоящую обёртку, запускает в Lua5.1 и проверяет оригинал, варианты thrown, пропуск обычного фонаря, неизвестный/пустой ID, повторную установку и отсутствующий модуль. Проверка включена в CI Linux; локально прошла вместе с 64 последовательностями пяти жизней. Нужен ресурсный CI и сетевой игровой тест. Работа кастомной HUD-анимации броска и третьего лица не объявлена готовой.

Отдельно: полный CI43269344509 на 0e717506d успешно завершил DX11, DX8 и нативные проверки предыдущей защиты восстановления. Эта новая серверная обёртка в тот запуск не входит. Выпуск установленного клиента/сервера остаётся 2026.11.12.1.
