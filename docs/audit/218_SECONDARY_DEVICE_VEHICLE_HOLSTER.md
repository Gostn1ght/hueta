# Вторичное устройство при посадке в транспорт

14 ноября 2026. Подготовлено, не выпущено.

netcoop_holster_in_vehicle убирал только ActiveItem. Устройство в DETECTOR_SLOT занимает вторую руку и не является активным предметом; оно оставалось показанным/работающим в транспортной позе. Отдельное отключение головного CTorch не покрывает CCustomDevice/CFlashlight. Имеющийся Lua ForceHide только отсоединяет HUD; его семантика сохранена, чтобы не ломать скриптовые анимации.

Новый CCustomDevice::netcoop_holster отменяет текущую анимацию без callback, отложенную активацию, zoom и pending, выключает работу/ручной свет виртуальным TurnDeviceInternal и переводит в eHidden. Текущий владелец с готовым HUD отправляет смену состояния; сервер/наблюдатели и владелец без HUD меняют состояние непосредственно. Безопасно отсоединяется только реальный HUD attachment. Повтор при каждом обновлении сидящего игрока не отправляет событие и не сбрасывает таймер сетевого refresh, если состояние не менялось.

Inventory вызывает это для DETECTOR_SLOT при той же проверке сидящего Actor, которая уже блокирует активный предмет. Никакого поиска по всему инвентарю или перемещения предмета в рюкзак нет. Предмет не должен сам показаться после выхода из машины.

check-native-inventory-hands исполняет реальный метод устройства вместе с настоящим inventory holster: две руки, выключение работы/света, отсутствие повторных событий/refresh flood, отсутствие самопоказа, dedicated/наблюдатель и отсутствие HUD у владельца, сохранение поведения вне машины/NPC/одиночной игры. Нативный запуск только в Actions. Общие АВТО-07/12/13 и АНИМ-04 этим не закрываются: новые клипы посадки/руления не добавлены.
