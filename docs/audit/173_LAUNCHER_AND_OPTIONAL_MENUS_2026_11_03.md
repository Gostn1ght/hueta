# Лаунчер и необязательная 3D-комната — 3 ноября

Выпущено **2026.11.03.2 / 000062**, лаунчер **1.3.0**. Предшествующий выпуск .1 и его исправления сохранены (аудит 172).

Исходники владельческого лаунчера 1.2.5 перенесены в `launcher/`, без ключей, dist/target и автоматически созданных файлов. `SOURCE_IMPORT.json` содержит хеши импортированных исходников. Рабочая старая папка лаунчера не перезаписывалась. Новый Windows workflow собирает 1.3.0 и проверяет его в GitHub Actions; локальный клиент, сервер и мастер для тестов не запускаются.

- Самообновление использует уже проверенный подписанный релиз и BLAKE3. Убрано требование install.json у переносимого лаунчера. Запуск из переносимой игровой папки с runtime-layout.json открывает лаунчер, а не установщик. Перезапуск сохраняет явный путь к игре и аргументы; неудачный запуск новой копии возвращает старый EXE. Мастер-копия сохраняет режим без автоматической перезаписи.
- Выбор рендера возвращён в интерфейс: DX11 и DX8/R1. Для выпуска нужен совпадающий DX8 из CI, его зависимости и проверка поставки. Один пункт в списке без EXE не считается выполнением.
- Встроенный каталог меню показывает состояние, требования и названия конфликтующих меню. Установка и удаление меняют один атомарный селектор в appdata/player, базовые архивы и сохранения не удаляются. Ресурсы комнаты входят в поставку; аддон активирует их. Для поддержки селектора требуется игровая версия данных 000062. При удалении возвращается classic. Темы «Костёр» и «Ночной лес» подготовлены и устанавливаются с тем же правилом взаимоисключения. Загрузка произвольных будущих графических пакетов, зависимости и их транзакционная установка ещё не реализованы.
- Стандартный клиентский frontend открывает 2D-меню с новой серой панорамой Зоны по настроению образца Anomaly. Вход в аккаунт-персонажа, выбор набора, сервер, маршрутизация и настройки используют прежние проверенные методы. Отсутствующий/неизвестный селектор выбирает classic. Только room создаёт модель и ожидает камеру; 2D не запускает радио. Нет новой регистрации при каждом входе и нет переноса данных аккаунта в лаунчер.

Настоящий Lua-код проверен отдельно для прежней комнаты и нового 2D-варианта: вход, серверные панели, отсутствие 3D-модели, ожидания камеры и музыки. Старые проверки аккаунтов, создания русской клички, набора, отмены и ожидания маршрута также прошли. Эти проверки не являются просмотром живого игрового окна. Подготовлены ещё два оригинальных фона по настроению примеров: укрытие с костром и лунный лес. В ночном варианте кнопки расположены слева. Все три изображения созданы встроенным image_gen, сохранены в assets/menu/addons вместе с точными промптами и manifest.json; DDS записаны без масштабирования при исходных 1672×941. Это новые статичные иллюстрации, а не оригинальные анимированные сцены других игр. Поддержка произвольных будущих аддонов остаётся открытой.

Первый ресурсный CI обнаружил смешанную кодировку новых подписей. Новые строки приведены к исходному UTF-8, проверка меню и стартового набора повторно пройдена. При просмотре выявлено, что существующий ui_background_new.ogm изображает Монолит, поэтому он исключён из кандидата и заменён оригинальными фонами. Новый лаунчер дополнительно проверяет себя каждые 10 минут, пока открыто видимое окно, и по кнопке проверки; игровые файлы такой проверкой не устанавливаются. Конкурирующие самообновления сериализованы файловой блокировкой, восстановление прежних байтов при ошибке перезапуска проверяется в CI без запуска игры.
