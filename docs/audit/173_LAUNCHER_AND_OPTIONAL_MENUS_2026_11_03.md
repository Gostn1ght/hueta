# Лаунчер и необязательная 3D-комната — 3 ноября

Кандидат, ещё не выпущен. Последний установленный игровой выпуск — 2026.11.03.1 / 000061 (аудит 172).

Исходники владельческого лаунчера 1.2.5 перенесены в `launcher/`, без ключей, dist/target и автоматически созданных файлов. `SOURCE_IMPORT.json` содержит хеши импортированных исходников. Рабочая старая папка лаунчера не перезаписывалась. Новый Windows workflow собирает 1.3.0 и проверяет его в GitHub Actions; локальный клиент, сервер и мастер для тестов не запускаются.

- Самообновление использует уже проверенный подписанный релиз и BLAKE3. Убрано требование install.json у переносимого лаунчера. Запуск из переносимой игровой папки с runtime-layout.json открывает лаунчер, а не установщик. Перезапуск сохраняет явный путь к игре и аргументы; неудачный запуск новой копии возвращает старый EXE. Мастер-копия сохраняет режим без автоматической перезаписи.
- Выбор рендера возвращён в интерфейс: DX11 и DX8/R1. Для выпуска нужен совпадающий DX8 из CI, его зависимости и проверка поставки. Один пункт в списке без EXE не считается выполнением.
- Встроенный каталог меню показывает состояние, требования и названия конфликтующих меню. Установка и удаление меняют один атомарный селектор в appdata/player, базовые архивы и сохранения не удаляются. Ресурсы комнаты входят в поставку; аддон активирует их. Для поддержки селектора требуется игровая версия данных 000062. При удалении возвращается classic. Неподготовленные темы «Костёр» и «Ночной лес» помечены «В разработке» и не устанавливаются. Загрузка произвольных будущих графических пакетов, зависимости и их транзакционная установка ещё не реализованы.
- Стандартный клиентский frontend открывает 2D-меню с панорамой Anomaly из имеющегося исходного OGM. Вход в аккаунт-персонажа, выбор набора, сервер, маршрутизация и настройки используют прежние проверенные методы. Отсутствующий/неизвестный селектор выбирает classic. Только room создаёт модель и ожидает камеру; 2D не запускает радио. Нет новой регистрации при каждом входе и нет переноса данных аккаунта в лаунчер.

Настоящий Lua-код проверен отдельно для прежней комнаты и нового 2D-варианта: вход, серверные панели, отсутствие 3D-модели, ожидания камеры и музыки. Старые проверки аккаунтов, создания русской клички, набора, отмены и ожидания маршрута также прошли. Эти проверки не являются просмотром живого игрового окна. Два дополнительных художественных варианта и поддержка всех будущих аддонов остаются открытыми.
