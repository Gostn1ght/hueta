# Отклонённая гипотеза: расстояние до трупа при восстановлении

13 ноября 2026. В выпуск не включать.

При проверке claim/rollback обнаружено, что set_switch_online лишь разрешает переключение. Была подготовлена временная правка 6ee1aeb18 и стенд ALife. GCC-стенд прошёл, но последующая проверка реального наследования выявила важное условие: CSE_ALifeCreatureAbstract::can_switch_offline возвращает false при get_health() <= 0, а try_switch_online уже поднимает такой объект независимо от расстояния. Стенд подменял этот метод общим разрешением и не доказывал новую причину тайм-аута именно мёртвого игрока.

Поэтому правка отменена целиком, полный экспериментальный CI 43446843780 отменён до выпуска. Она не считается закрытием задачи. Проверенные исправления 541b2bd03 (резерв отдельных вещей), 29906193a (поздний резерв перед очисткой), 90aa9c861 (защита незавершённого тела) сохранены. Исходный тайм-аут без серверного лога остаётся не полностью воспроизведённым.
