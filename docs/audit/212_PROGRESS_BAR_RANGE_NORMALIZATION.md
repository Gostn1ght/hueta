# Нормализация диапазона полосы HUD

13 ноября 2026. Подготовлено, не выпущено.

CUIProgressBar::UpdateProgressBar делил текущее значение на max-min без вычитания min. Для диапазона [50,150] значение 50 давало половину полной полосы и средний цвет вместо пустой полосы/минимального цвета. При смене диапазона сохранялись старые отображаемое и целевое значения; градиент мог получить долю за пределами [0,1].

Расчёт теперь использует (current-min)/(max-min) с ограничением [0,1]. SetRange ограничивает текущее/целевое значение новым диапазоном; обратный диапазон сводится к пустому, существующая защита равных границ сохранена. Обычные полосы [0,100] не меняют нормализацию. Это конкретное исправление арифметики UI, не подтверждение причины всех сообщений о красном HUD после перехода.

CI-only check-native-progress-range.py исполняет реальные UpdateProgressBar, SetRange и SetProgressPos: положительный/отрицательный минимум, четыре направления, цвет и длина в крайних/средних точках, сужение диапазона, цель за границей, равные/обратные границы, одноцветный режим. Локально выполнена только Python-проверка синтаксиса; нативная проверка и полная сборка требуются в GitHub Actions.
