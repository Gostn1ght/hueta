# HOM CPU preparation without parallel raster mutation

The owner deferred launcher publication and requested autonomous multithreading completion, then other serious tasks. The transient84public pointer was restored to the previous signed80/news/chunkstore before provider reload or client probe; immutable84payloads and local84 remain intact. No further publication is performed in this task.

HOM currently clips and projects every selected triangle serially. Its software rasterizer has global currentTri/currentA/B/C/dwPixels scratch and shared frame/depth buffers, so rasterization must remain ordered on its original owner. The new synchronous batch computes only side eligibility, single-near-plane ClipPoly and projected vertices from frozen geometry/frustum/camera/matrix. Prepared output is indexed by the existing sorted order. The owner retains every RNG draw, skip update, raster fan and raster call in its original order. Maximum65536records of52bytes bounds scratch at3.25MiB; inputs below1024, serial/legacy flags and allocation failure retain the old loop. Unexpected polygons over4vertices discard preparation before owner mutation.

Load, Unload and direct Render now share the existing recursive HOM critical section with MT_RENDER. This protects borrowed model/triangle data through the CPU fence; workers call no engine callbacks/GPU/raster/global RNG and write only their output. -cpu_hom_legacy/-cpu_serial retain serial processing; -cpu_trace reports actual HOM slots for eligible batches.

CI compiles the actual ClipPoly and matrix-transform bodies plus actual software rasterizer core/propagation and new preparation helper. Vector/frustum container boundaries are doubles; full DX11/DX8 is required for engine ABI. The fixture compares raw depth/frame pointers/mip values/skip fields/RNG state between the old owner path and serial/parallel preparation, covers near-plane fans/degenerate/boundary inputs and forced scheduler failure, and checks preparation does not mutate shared occluders. No game/GPU is executed locally, no gameFPS claim. Native evidence is pending at this commit.
