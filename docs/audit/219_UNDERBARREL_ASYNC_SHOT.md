# Отложенный первый выстрел подствольного гранатомёта

14 ноября 2026. Кандидат, не выпущен.

При загруженном патроне сервер отвергал выстрел, если ownership дочерней гранаты ещё не пришёл. Добавлено ожидание с сохранением владельца, секции патрона и первоначальных координат/направления. Одновременно запрашивается не более одной дочерней гранаты; повторный выстрел во время ожидания не расходует патрон. При новом ownership выбирается именно fake_grenade_name загруженного патрона. Приход старого другого типа запускает один запрос правильного типа.

Патрон и OnShot применяются при действительном запуске. Смена владельца, удаление оружия, переход в винтовочный режим или смена патрона отменяют отложенный выстрел без расхода. При запуске восстанавливаются исходное направление и контекст актора для GAMMA callbacks. Существующее баллистическое прицеливание LaunchGrenade сохранено. Скорость, создание при переключении и перезарядке теперь берутся из фактического патрона; пустое оружие не создаёт лишнюю гранату.

check-native-projectile-shot исполняет реальные dispatch/selection/pending/ownership методы с границей LaunchGrenade, замещённой счётчиком. Проверяются один запрос/патрон/эффект, исходное направление после движения прицела, контекст актора, шесть вариантов отмены и старый снаряд другого типа. Сам баллистический LaunchGrenade этим стендом не исполняется. Локально проверяются только Python AST и diff; GCC/MSVC и полный DX11/DX8 — Actions. Модель M79 и все игровые случаи этим не объявляются закрытыми.
