# Оружейный слой ползания после отклонённого предпросмотра

Владелец отклонил винтовочную позу движения вперёд: правый локоть поднимался, предплечье пряталось у корпуса. Первый показанный неподвижный хват выбран владельцем как ориентир. Кандидат 000069 не опубликован и не устанавливается; следующий пакет — 000070.

Исправление использует проверенный хват из прежнего rifle idle как отдельную сборку рук. Захваченный цикл продолжает двигать тело/ноги, оружие с обеими руками следует позиции родительской кости шеи и направлению тела. Наклон грудной клетки при толчке не направляет ствол в землю. Поворот прицеливания остаётся штатной поправкой ShoulderCallback для prone: дети плеча/шеи, обе руки и оружие поворачиваются вместе. Кости не растягиваются; исходный скелет имеет родителя clavicle = neck, а не spine2.

Добавлена проверка каждого декодированного кадра всех пяти винтовочных циклов: направление крепления вперёд, правый локоть ниже плеча, расстояние между ладонями неизменно. Проверка всего пакета сохраняет ограничения длины 47 костей и подвижность ног. Просмотр с настоящими OGF актёра и АК-74/LTX показывает кисть на рукояти и ствол вперёд в разных фазах. Это не проверка каждого оружия/костюма в игре.

Чужие цельные циклы также исследованы по запросу владельца: исходники Prone Mod (Stiffy360, George Petrou), commit 1aef0e70ee49ddfdaa323157ae5136fb58bf5598. Частный перенос 29 кадров и слоёв использовался для проверки схемы движения. Он не включён в игровые ресурсы. Поставляемые исходные движения остаются официальными Mixamo; сырые FBX приватны. Специальный хват РПГ, полный набор переходов посадки/дверей и семь оставшихся водительских профилей не закрыты.
