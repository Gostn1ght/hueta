# Исходные движения для проверки переноса

Четыре движения Mesh2Motion, CC0-1.0: низкое ползание, лежачая поза с пистолетом руление и спокойная пассажирская посадка. Источник, закреплённый коммит, лицензия и контрольные суммы находятся в `provenance.json`. Входные GLB распакованы из EXT_meshopt_compression официальным декодером meshoptimizer без изменения ключей; это исходники для Blender, не игровые анимации.

`tools/retarget-cc0-player-anims.py` переносит их на настоящий 47-костный игровой OGF и пишет отдельный OMF, Blender-сцену, координаты контрольных костей и обзор реальной модели. Игровые файлы инструмент не заменяет. Донор смотрит по -Y, игровой персонаж — по +Y; направление и длины сегментов учитываются при переносе.

**Не закрывает АНИМ-02/04:** пока не проверены хваты настоящего оружия, смена направлений, контакт с рельефом и привязка к сиденьям/рулю. Движений открытия двери, посадки и выхода в этом наборе нет. Обычное присаживание не выдаётся за посадку в автомобиль.

Новый пассажирский цикл заменяет только lz_vehicle_passenger в исходниках следующего обновления. Его таз находится в посадочном нуле; ключи экспортированного OMF проверяются отдельно от Blender. Дверные переходы и новые хваты руления этим изменением не заменены.
