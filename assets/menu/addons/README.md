# Готовые меню Anomaly для Lost Zone

Источник: [Animated main menus](https://www.moddb.com/mods/stalker-anomaly/addons/animated-main-menus), автор **karatel_196rus**, credits: **xomut**. На странице автора указана лицензия Public Domain. Точные контрольные суммы архива и выбранных файлов находятся в `manifest.json`.

В кандидат включены оригинальные OGM 1920×1080: туманный мост Кордона (стандарт), костёр в ангаре (`campfire`) и ночное убежище при свече (`night`). Видеопакеты Theora сохранены побайтно; контейнер перемонтирован для удаления аудио и служебного потока, без перекодирования, генерации или изменения разрешения. Хеш и число кадров сверены с оригиналом. Названия сцен сохранены по папкам автора; не следует выдавать ночное убежище за лес из S.T.A.L.K.E.R. 2.

Использованы фоновые сцены и компактная текстовая компоновка аддона; действия заменены на аккаунт-персонажа и подключение Lost Zone. Логотип Lost Zone выводится интерфейсом поверх видео. Чужие одиночные сценарии входа/новой игры и музыка не перенесены. Изображения `*-author-preview.png` — исходные иллюстрации автора из FOMOD, не скриншоты адаптированного интерфейса.

Сгенерированные фоны предыдущего выпуска исключены из активного overlay. Старые архивы выпуска 000062 не изменяются; кандидат использует новое имя `ui/lz_addon_*`, чтобы прежние DDS не подменяли выбранный фон. Публикация и установка пока не разрешены пользователем.
